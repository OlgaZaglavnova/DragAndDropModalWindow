# DragAndDropModalWindow

Learning project created during the GeekBrains Frontend Developer course.

This repository contains a JavaScript practice project focused on creating interactive UI elements without using frontend frameworks.

---

## 📌 About The Project

The goal of this project was to practice working with browser APIs, DOM manipulation and user interactions.

The project demonstrates:

- creating modal windows;
- implementing drag and drop functionality;
- handling mouse events;
- working with DOM elements;
- managing UI interactions with JavaScript.

---

## ✨ Features

Implemented functionality includes:

- opening and closing modal windows;
- moving elements using drag and drop;
- handling user mouse interactions;
- dynamic element positioning;
- working with JavaScript events.

---

## 🛠 Technologies

- JavaScript
- HTML5
- CSS3

---

## 🎯 Purpose

This project was created while studying frontend development fundamentals.

It helped strengthen my understanding of:

- JavaScript event handling;
- DOM manipulation;
- browser interaction patterns;
- creating interactive web interfaces.
